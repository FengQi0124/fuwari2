## 网站性质

本网站是一个静态网站，这意味着：
- 我们不会在服务器端存储您的个人信息
- 网站内容是预先生成的，不会动态处理用户数据
- 我们不会主动收集或存储您的个人信息

## 第三方服务

尽管本网站本身是静态的，但我们使用了以下第三方服务，这些服务可能会收集和处理您的信息：

### CDN 和托管服务

本网站由以下服务提供商托管：

**Vercel**
- 可能收集的信息：IP 地址、访问日志、性能数据
- 用途：网站托管

**CloudFlare**
- 可能收集的信息：IP 地址、访问时间、请求的页面、浏览器信息
- 用途：提供 CDN 服务、网站加速

### 评论系统

本站使用 **Giscus** 评论系统，基于 GitHub Discussions：
- 评论内容存储于 GitHub 仓库中
- 评论时需使用 GitHub 账号登录
- 您的评论数据受 GitHub 隐私政策约束

## Cookie 和本地存储

我们的网站可能使用以下技术：
- **Cookie**：用于网站功能和第三方服务
- **本地存储**：用于保存用户偏好设置（如主题选择、字体偏好）
- **会话存储**：用于临时存储页面状态

您有权：

## 如何保护您的隐私

您可以通过以下方式保护您的隐私：
- 使用隐私浏览模式
- 禁用第三方 Cookie
- 使用广告拦截器

- 定期清理浏览器数据

## 数据安全

虽然我们不直接收集您的个人信息，但我们：
- 使用 HTTPS 加密传输
- 选择信誉良好的第三方服务提供商
